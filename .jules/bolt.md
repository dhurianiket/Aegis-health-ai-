## 2024-06-25 - React Component Re-render Performance via Memoization
**Learning:** Performing inline `.filter()` operations on arrays directly inside render blocks (e.g., within `.map` calls or derived state calculations) forces React to create new array instances on every render. This not only consumes CPU cycles for recalculation but also triggers unnecessary re-renders of child components that receive these arrays as props, causing performance bottlenecks in data-heavy components like `Timeline`, `Dashboard`, and `LabReportsSection`.
**Action:** Always extract derived array calculations (like `.filter()`, `.map()`, or sorting) into `useMemo` hooks, specifying the base array and filter conditions as dependencies. This ensures the calculation only runs when the underlying data or filter parameters change, preserving referential equality and optimizing rendering performance.
